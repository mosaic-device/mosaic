Set up Mosaic

Save Wi-Fi settings and a secure server URL. Mosaic tests the Wi-Fi connection only after reboot. This does not pair your device.

Settings are saved without testing Wi-Fi. After saving, Mosaic waits about six seconds, then reboots and tries connecting.

If the Wi-Fi settings are wrong, Mosaic shows an offline screen after reboot; setup does not reopen automatically. Tap Enter setup mode twice on the device to try again. The server URL is checked for format only. Public Wi-Fi that requires a web sign-in is not supported.
